# Download speed

Консольный скрипт на Node.js. Делает 10 запросов к указанному адресу строго по очереди, дожидается полного тела ответа на каждый и печатает среднее время, объём скачанных данных и скорость.

Зависимостей нет: используются только модули `node:http` и `node:https`.

## Требования

- Node.js 18 или новее

## Запуск

```bash
node measure.js <url>
```

Пример — файл на 1 МБ:

```bash
node measure.js https://proof.ovh.net/files/1Mb.dat
```

Адрес обязателен. Подходят только `http` и `https`. Редиректы (до 5) скрипт проходит сам. Если ответ не успешный или сеть оборвалась, скрипт останавливается и завершается с кодом 1 — частичный замер в среднее не попадает.

## Что считается

На каждый запрос таймер стартует в момент отправки и останавливается, когда тело ответа полностью прочитано. Сжатие отключено (`Accept-Encoding: identity`), поэтому в объём входят байты тела ответа как они пришли по сети, без заголовков HTTP.

- **Среднее время запроса** — сумма длительностей 10 запросов, делённая на 10. Единица: **миллисекунды (ms)**.
- **Общий объём** — сумма размеров тел всех 10 ответов. Единица: **мебибайты (MiB, 1 MiB = 1024² байт)**; рядом печатается точное число байт.
- **Скорость скачивания** — весь скачанный объём, делённый на суммарное время 10 запросов. Единица: **мегабит в секунду (Mbit/s)**. Мегабит здесь десятичный, как у провайдеров и спидтестов: 1 Mbit = 1 000 000 бит. Формула: `(всего байт × 8) / 1_000_000 / (суммарные миллисекунды / 1000)`.

## Пример вывода

```
URL: https://proof.ovh.net/files/1Mb.dat
Requests: 10, one after another

#01     180 ms   1.00 MiB
#02     160 ms   1.00 MiB
...
#10     170 ms   1.00 MiB

Average request time: 172 ms
Total downloaded:     10.00 MiB (10485760 bytes)
Download speed:       48.76 Mbit/s
```
